## Opening files

Perhaps the last one convinced you that even the most basic things can be upgraded. But "opening files"?? Really?

Yep. I've usually only used the regular `open` in Zshell when it'd be easier for my to type `open <name>.png` than copying the path and clicking into Finder to let the default app (Preview) open it. for example when I generated a PPM image in my [raytracing project](https://github.com/sreyassabbani/ray-tracing-rs), it saved me a ton of time.

Ever since I switched to Nushell, I found its `open` command to be mostly a hindrance because it just didn't function at all like Zshell's `open` command. However, once I found what it was capable of, I immediately started using it.

# Fun

## Typing test

From [`lemnos/tt`](https://github.com/lemnos/tt):

<TerminalTranscript
  label="Starting a typing test"
  transcript={`sreysus [λ] tt`}
/>

A nerdier version of [monkeytype](https://monkeytype.com)

You can run in the format of `tt -n 10` for a 10-word test or `tt -t 20` for a 20-second test. Also, I have my system configured so that `tt` is [an alias to](https://github.com/sreyassabbani/config/blob/2ed6b6c2c52a2f66c59a903d43730c128688c070/home/tt.nix#L12) `tt -theme catppuccin-frappe`, which itself is derived from a [custom theme file written](https://github.com/sreyassabbani/config/blob/2ed6b6c2c52a2f66c59a903d43730c128688c070/home/tt.nix#L3-L10) @ `~/.tt/themes/catppuccin-frappe`.
